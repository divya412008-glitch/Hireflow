# HireFlow

## Intelligent Applicant Tracking & Hiring Management System

HireFlow is a full-stack recruitment management system designed to manage the hiring lifecycle from job creation to candidate hiring.

The system provides job management, candidate management, applications, hiring pipeline tracking, interview scheduling, interviewer panel assignment, interview feedback, business-rule validation, and recruitment funnel analytics.

---

## Features

### Job Management
- Create and manage job openings
- Store title, description, location, experience, and status
- View available job openings

### Candidate Management
- Store candidate information
- Manage contact details, skills, experience, and resume information
- View candidate profiles

### Application Management
- Apply candidates to job openings
- Track each application through the hiring pipeline
- Connect candidate, job, and pipeline stage
